# SpecShift planning pack

Approved next portfolio project for Ayotomiwa Ojo. Completed 9 October 2026. Planning only: no application, remote repository, provider resources, or deployments have been created.

SpecShift is a visual API change-review studio. Its value is the connection between a specific contract change, the operations that depend on it, and the exact evidence for a bounded compatibility finding.

## Start here

Open the independent project folder at `../../projects/specshift` from this pack. Read its root `AGENTS.md`, then paste `ANTIGRAVITY-HANDOFF.md` into Antigravity. That folder is a portable copy of this planning pack, ready for implementation; it is not yet an initialized Git repository. The outputs copy is the delivered planning baseline. After implementation begins, the project copy becomes authoritative; do not maintain two evolving versions.

## Reading order and authority

1. `product-spec.md`: scope, journeys, release acceptance.
2. `CONTEXT.md`: canonical domain language only.
3. `compatibility-rules.md`: classification and coverage authority.
4. `architecture.md` and `security-and-privacy.md`: modules, API, resource boundaries.
5. `interface-brief.md`: visual and interaction contract.
6. `implementation-plan.md`: one end-to-end sequence with automated gates.
7. `hosting-and-operations.md`: free deployment and recovery.
8. `demo-and-fixtures.md`: demonstration and evidence.
9. `sources-and-decisions.md`: current technical evidence and rationale.

No ticket-by-ticket approval workflow. Codex and Antigravity implement and verify; Ayotomiwa reviews meaningful outcomes. Routine choices proceed autonomously. Account access, external publication permission, and material scope changes remain user-controlled.

## Practical decisions

- Python 3.13, Django 5.2 LTS with Django REST Framework; React/TypeScript/Vite and MIT-licensed React Flow (`@xyflow/react`) with deterministic layered layout.
- OpenAPI 3.0.x JSON/YAML, single document per side, internal references only. Unsupported versions fail clearly; unsupported constructs produce explicit uncertainty.
- No LLM, paid API, map tiles, subscriptions, required credit card, accounts, private cloud archive, or background queue.
- Stateless comparisons. PostgreSQL is deliberately deferred until private saved history is a requested feature. No SQLite database on an ephemeral host.
- Cloudflare Pages Free frontend and Render Free API, conditional on actual account eligibility without payment details. See hosting gate before publication.
- Immediate bundled example is generated by the Python engine during build/CI, visibly labelled as a recorded synthetic comparison; arbitrary uploads require the live Python API.
